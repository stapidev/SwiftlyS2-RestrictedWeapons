Гибкий, производительный и оптимизированный плагин ограничения покупки и подбора оружия в зависимости от текущего онлайна на сервере или в отдельной команде.

---

## Ключевые возможности

- **Динамические лимиты оружия**: Настройка ограничений на любое оружие при разном количестве игроков.
- **Гибкие типы подсчета онлайна**:
  - Подсчет общего количества игроков на сервере или отдельно в каждой команде (`type_players`).
  - Опциональный учет или игнорирование наблюдателей / зрителей (`spec_players`).
- **Ограничения по командам или серверу**: Подсчет существующих стволов на сервере или отдельно у каждой команды (`type_weapons`).
- **Полная поддержка ботов**: Учет ботов при расчете активного оружия и онлайна без отправки им лишних чат-сообщений.
- **Звуковые эффекты и защита от спама**:
  - Воспроизведение звука отказа покупки/подбора (`block_sound`).
  - Защита от спама звука при нахождении поверх ограниченного оружия (`interval_sound`).
  - Задержка между текстовыми сообщениями об ограничении (`interval_message`).

---

## Конфиг (`config.jsonc`)

Конфигурационный файл создается автоматически по шаблону при первом запуске плагина.

```jsonc
{
  "RestrictedWeapons": {
    // Звук блокировки покупки/подбора оружия
    "block_sound": "sounds/ui/weapon_cant_buy",

    // Интервал в секундах между проигрыванием звука блокировки одному игроку (когда игрок стоит на оружии)
    "interval_sound": 3,

    // Тип подсчета игроков: 1 - общее количество игроков, 2 - количество игроков в вашей команде
    "type_players": 1,

    // Считать ли наблюдателей при подсчете общего онлайна (true - да, false - нет)
    "spec_players": false,

    // Тип подсчета оружия: 1 - общее количество оружия на сервере, 2 - количество оружия в вашей команде
    "type_weapons": 1,

    // Интервал в секундах между отправкой сообщений об ограничении одному игроку
    "interval_message": 3,

    // Глобальные пороги ограничений оружия ("онлайн": { "оружие": лимит })
    // Лимит: -1 = без ограничений, 0 = запрещено совсем, N = максимум N штук на сервер/команду
    "weapons": {
      "0": {
        "weapon_awp": 0,
        "weapon_negev": 0
      },
      "8": {
        "weapon_awp": 1,
        "weapon_negev": 1
      },
      "12": {
        "weapon_awp": 2,
        "weapon_negev": -1
      }
    }
  }
}
```
